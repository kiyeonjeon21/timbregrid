# TimbreGrid v0.1.0-alpha.1

This is the first public alpha for TimbreGrid's local-first OSS TTS compatibility and evaluation layer.

## What is included

- A lightweight Docker image that starts the deterministic `fake:tts` gateway by default.
- `POST /v1/audio/speech` and `GET /v1/audio/voices` in the reference gateway.
- Manifest validation, generated registry artifacts, and support matrix output.
- Benchmark suites, raw benchmark JSON validation, and checked-in Kokoro/KittenTTS Apple Silicon submissions.
- Basic OpenAI-compatible speech conformance checks.
- Optional Kokoro and KittenTTS adapters for local real-model synthesis.

## Try the alpha container

```bash
docker run --rm -p 8889:8889 ghcr.io/kiyeonjeon21/timbregrid:0.1.0-alpha.1
```

Then call:

```bash
curl http://localhost:8889/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{"model":"fake:tts","input":"Hello from TimbreGrid","voice":"alloy","response_format":"wav"}' \
  --output speech.wav
```

The default image intentionally serves deterministic test audio. Install optional adapters from source when you want Kokoro or KittenTTS synthesis.

## Registry

- Hosted latest registry: https://kiyeonjeon21.github.io/timbregrid/registry/index.json
- Versioned release asset: `registry/index.json` attached to this release.

## Caveats

- This is a prerelease, not a stable API guarantee.
- PyPI publishing is not enabled yet.
- The Docker image does not include Kokoro, KittenTTS, `espeak-ng`, or PyTorch-class model dependencies.
- Chatterbox and Qwen3-TTS are manifest-only examples in this release.
