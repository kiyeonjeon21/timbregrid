# TimbreGrid v0.1.0-alpha.2

This alpha makes TimbreGrid easier to try as a CLI diagnostic tool while keeping the package metadata safe for PyPI.

## What Changed

- Published the first PyPI alpha package through Trusted Publishing.
- Removed the KittenTTS direct GitHub wheel dependency from published optional extras.
- Kept the KittenTTS adapter executable from a source checkout with an explicit install command.
- Added external-server doctor proof documentation for Speaches.
- Updated Open WebUI and release documentation around `timbregrid doctor` preflight checks.

## Try The CLI

```bash
uvx --from timbregrid==0.1.0a2 timbregrid --help
uvx --from timbregrid==0.1.0a2 timbregrid models list
uvx --from timbregrid==0.1.0a2 timbregrid doctor --help
```

## Try The Container

```bash
docker run --rm -p 8889:8889 ghcr.io/kiyeonjeon21/timbregrid:0.1.0-alpha.2
```

Then call:

```bash
curl http://localhost:8889/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{"model":"fake:tts","input":"Hello from TimbreGrid","voice":"alloy","response_format":"wav"}' \
  --output speech.wav
```

## Caveats

- This is a prerelease, not a stable API guarantee.
- The Docker image intentionally serves deterministic fake audio by default.
- The Docker image does not include Kokoro, KittenTTS, `espeak-ng`, or PyTorch-class model dependencies.
- `timbregrid[kokoro]` is available as an optional PyPI extra; KittenTTS is installed explicitly from a source checkout.
- Chatterbox and Qwen3-TTS are manifest-only examples in this release.
